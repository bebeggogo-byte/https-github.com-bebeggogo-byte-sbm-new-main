# 아우라토 사이트 리뉴얼: 리서치와 구조 (2026-11-13)

## 1. 리서치 결과와 반영

| 조사 내용 | 확인한 사실 | 사이트 반영 |
|---|---|---|
| 경쟁 가격(공개 판매 페이지, 2026.11) | 재능마켓 문항 첨삭 1.5만~3만원, 모의면접 30분 4만원, 패키지 2만~9.9만원. 간호 전문 교육 사이트 1:1 첨삭 8.8만원(정가 13만원), 무한 첨삭 25만원. 일반 취업학원 1:1 자소서 30만원 | 홈에 '시중 서비스 비교' 표를 추가함. 가격이 아니라 구성(화상 2회, 기관 분석, 면접 포함, 보고서)으로 차별화 |
| 신청 폼 칸 수 | 칸이 늘수록 전환이 떨어지고 드롭다운이 여러 개면 더 떨어진다는 업체 조사(HubSpot 4만 페이지, NP Digital 404 페이지). 수치는 조사마다 달라 방향만 참고 | 홈 첫 화면에 '1분 신청'(이름, 휴대폰, 직종 버튼)을 둠. 컨설팅 페이지 설문은 선택 항목으로 접음 |
| 전면 팝업 | 구글은 모바일 검색 유입 직후 내용을 가리는 팝업에 불이익을 줌(2017 도입, 2021 페이지 경험 신호에 통합) | 모바일은 내용을 가리지 않는 하단 카드로 바꿈. 데스크톱은 30% 스크롤 또는 12초 뒤에만 팝업 |
| 2027 국시 일정 | 약사 2027-01-21(대학 공지 경유). 임상병리사 등 3개 시험은 2027년부터 컴퓨터시험 확대(2년 전 기사). 방사선사·임상병리사 시험일은 확인 못 함 | 일정 카드는 '예년 시기' 표기를 유지함. 국시원 공고를 확인한 뒤 exams.js에 입력 |

### 가격에 대한 판단(대표 결정 필요)
- 시중 최고가가 약 30만원이라 **정가 80만원은 시장 대비 2.5배 이상**입니다. '87.5% 할인'은 소비자가 믿기 어렵고, 표시광고법상 종전 가격 근거도 필요합니다.
- 프로모션가(10만~28만원)는 시장 범위 안에 있어 경쟁력이 있습니다.
- 그래서 새 홈에서는 할인율 배지를 빼고 '1인 10만원'과 구성으로 설득합니다. 정가는 하단에 한 줄로만 표기합니다.
- 권장: 정가를 30만~40만원대로 낮추거나, 80만원 판매 실적(기관 계약 단가 등)을 근거로 확보합니다.

## 2. 사이트 구조(퍼널 기준)

```
/                      아우라토 홈: 1분 신청, 상황별 분기, 근거, 방식, 비교, 가격, FAQ
├─ /consulting/        상세 설득: 직종, 목표 기관, 보고서 예시, 가격 조건, 신청+선택 설문
│   └─ /after-exam/    국시 응시자: 3주 계획, 사전예약
├─ /colleges/          기관(B2B): 운영 실적, 제공 서류, 견적 요청
└─ /nedabah/           네다바웨이: 교육 프로그램, 소개, 의뢰 폼(기존 홈 이전)
    ├─ /programs/…     프로그램·노트
    └─ /growth/        성장 기록
```

| 퍼널 단계 | 방문자 질문 | 화면 요소 |
|---|---|---|
| 인지 | 나한테 해당되나 | 히어로 문장, 직종 칩, 상단 프로모션 띠 |
| 분기 | 내 상황은 | '지금 어떤 상황인가요' 카드 3장(지원 중, 국시 준비, 기관) |
| 신뢰 | 믿을 만한가 | 근거 3종(출처 표기), 수정 전·후, 컨설턴트 FAQ |
| 비교 | 다른 데보다 나은가 | 시중 서비스 비교표 |
| 결정 | 얼마인가, 지금 해야 하나 | 가격 티켓, 카운트다운, 오른쪽 바 'D-n' |
| 행동 | 어떻게 신청하나 | 1분 신청 폼(첫 화면), 오른쪽 바, 모바일 하단 바 |
| 확장 | 친구, 학교 | 함께 신청 가격, 기관 의뢰 링크 |

## 3. 오른쪽 컨트롤 바(quickbar.js)
- 데스크톱 화면 오른쪽에 고정합니다. 항목: 마감 D-n, 신청, 가격, 보고서, 국시 직후, 학교·기관, DM 문의, 스크롤 진행 막대, TOP.
- 화면 폭 1100px 이하에서는 숨기고, 모바일은 하단 고정 바를 씁니다.
- 홈, 컨설팅, 국시 직후, 기관 페이지에 공통으로 적용했습니다.

## 4. 로고
- 네다바웨이와 같은 글자 로고 방식입니다. `AURA` 남색에 `TO` 파란색, 자간을 넓혔습니다.
