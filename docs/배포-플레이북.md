# 무료 배포 플레이북 (Distribution Playbook)

> 사이트·글·OG·구조화데이터는 충분히 갖췄습니다. 이제 **퍼뜨려야** 트래픽이 생깁니다.
> 이 문서는 계정·돈 없이 바로 실행하는 배포 루틴입니다. 색인(검색엔진 등록)과 병행하세요.

## 우선순위
1. **검색엔진 색인 켜기**(노출 스위치): GSC 확인 + IndexNow 제출 + 네이버 등록 — `docs/검색엔진-등록-가이드.md`, `docs/indexnow-제출.md`
2. **이 플레이북 실행**(색인과 함께 트래픽 생성)
3. 글 더 쌓기 (1·2 없이는 효과 0)

---

## 1) 네이버 블로그 — 주 1~2회, 한 주제로 (C-Rank 적립)
- 원칙: 사이트 글을 **그대로 복사하지 말 것**(중복). 블로그용으로 풀어 쓰고, 끝에 원문 1링크.
- 한 채널을 "제주 신앙공동체/묵상·자기계발" 한 주제로 꾸준히 → 창작자 신뢰(C-Rank) 적립.
- 4주 발행 계획:
  | 주차 | 블로그 제목(예) | 연결 글 |
  |---|---|---|
  | 1주 | 혼자 큐티가 자꾸 멈추는 이유, 그리고 다시 시작하는 법 | /programs/sbm/read-together/ |
  | 2주 | 작심삼일을 진짜 끝내는 법 — 정체성에서 시작하기 | /programs/iden/identity-habits/ |
  | 3주 | AI 처음 쓸 때, 첫 과제 이렇게 고르세요 | /programs/ai-lab/first-ai-task/ |
  | 4주 | 강의보다 워크숍이 남는 이유(225개 연구) | /programs/workshop/why-workshops-stick/ |
- 1주차 완성 원고: 아래 `docs/네이버-1주차-원고.md` 참고(복붙용).

## 2) 커뮤니티·오픈채팅 — 가치 우선(자기홍보 10% 이하)
- 질문이 올라오는 곳(제주 지역카페, 자기계발/AI 오픈채팅 등)에 **먼저 도움이 되는 답**을 달고, 끝에 "정리해둔 글 있어요" + 링크 1개.
- 금지: 링크만 투척, 같은 글 도배, 사칭. (신뢰 무너지면 SEO·평판 동반 하락)

## 3) 복붙용 공유 문구 (카톡/인스타/스레드)
```
작심삼일이 의지 문제가 아니라는 글 — "정체성에서 시작하면 습관이 붙는다"
https://nedabah.org/programs/iden/identity-habits/
```
```
AI한테 일 제대로 시키는 법: 역할·맥락·예시·형식
https://nedabah.org/programs/ai-lab/how-to-prompt/
```
```
혼자 큐티가 자꾸 멈춘다면 — 의지가 아니라 구조의 문제예요
https://nedabah.org/programs/sbm/read-together/
```
> 이제 링크를 붙이면 **썸네일(OG 카드)**이 떠서 클릭률이 높습니다.

## 4) 지인 1:1 전달 (전환율 최고)
- 각 글 하단 **공유 버튼**으로, 그 주제가 떠오르는 한 사람에게 직접 전달.
- 예: 자녀 교육 고민하는 지인 → 청소년 리더십 글 / 반복업무에 지친 지인 → 자동화 글.

## 5) 새 글 올릴 때마다
- 그 URL을 IndexNow로 1회 제출(색인 가속).
- 네이버 블로그·공유 1회씩.

## 측정(주간)
- GSC 실적: 노출수·클릭수·검색어
- GA4(연결 시): 유입 경로·체류·문의 전환
- 추천 유입(레퍼럴) 비율, 공유 발생 수
