## 3. 전략

### 기업 (주력 확장)
1. 위치: 현직자 멘토링의 대체재로 내세우지 않는다. "경험 정리와 자기소개서·면접 답변 일치"를 담당하는 서비스로 표시한다.
2. 진입: 무료 키워드 테스트(/keyword/)를 첫 단계로 둔다. 테스트 결과를 가진 사람에게 2회 과정을 안내한다.
3. 가격: 총 3인 신청(1인 100,000원)을 기본으로 안내한다. 같은 스터디 구성원 3명이 대상이다. 총 1인 280,000원은 시중 평균보다 높으므로 보고서와 자기소개서 수정 포함을 근거로 표시한다.
4. 채널: 취업 스터디, 대학 취업 커뮤니티, 에브리타임. 수시채용이 54.8%이므로 캠페인 시기를 고정하지 않는다.
5. 측정: 키워드 테스트 완료 수, 기업 페이지 신청 수, 총 3인 신청 비율.

### 임용 (소규모 시험 판매)
1. 위치: 학원 강의와 스터디의 보완재. 페이지에 "맞지 않는 경우"를 명시해 환불 요청과 불만을 줄인다.
2. 시기: 유·초등은 현재부터 1월 5일, 중등은 12월 29일부터 1월 19일.
3. 가격: 총 3인 신청을 스터디 3명 단위로 안내한다.
4. 판단 기준: 2027년 1월 20일까지 신청 5건 미만이면 2028학년도에는 분야 목록에서 제외한다. 5건 이상이면 응시자 후기 동의를 받아 다음 해 자료로 사용한다.
5. 금지: 합격률, 교육청별 적중 표현, 교사 출신으로 읽힐 수 있는 표현.
