> **버전** v1.0 · **작성일** 2026-05-31 · **대상 사이트** https://nedabah.org
> **범위** 온라인 100% · 유료 광고 0원(유기적/무료 채널만) · 운영 리소스는 Claude Max 구독 범위 내

## 0. 이 문서의 사용법

이 로드맵은 "읽는 문서"가 아니라 **실행하는 문서**입니다. 각 파트는 ① 무엇을(What) ② 왜(Why·근거) ③ 어떻게(How·단계) ④ 무엇으로 확인하나(Verify·측정) 네 칸으로 구성됩니다. 마지막 파트의 **전략 평가 루브릭 / 실행 평가 루브릭**으로 매주 자가 채점하여 100점에 수렴시키는 것이 목표입니다.

문서 구성(목차):

1. 현황 진단 & 솔직한 피드백
2. 전략 목표와 핵심 가설
3. 카테고리 개별 분리 전략 (필러–클러스터)
4. 검색·AI 노출 최적화 (SEO + GEO/AEO + 네이버)
5. 9단계 심리 흐름 설계
6. 대상(타깃) 선정과 자연 확산 설계 + 윤리 가드레일
7. 24단계 실행 로드맵 (0~24주)
8. 채널별 실행 디테일 (무료 채널만)
9. 측정·실행검증 체계 (KPI / 대시보드)
10. 전략 평가 루브릭 (100점)
11. 실행 평가 루브릭 (100점)
12. 리스크 관리 & 자료 출처

## 1. 현황 진단 & 솔직한 피드백

### 1.1 지금까지 무엇이 되어 있나 (사실 확인)

저장소와 실제 사이트 구조를 점검한 결과, **기반 작업(Foundation)은 끝났고 홍보(Distribution)는 0에 가깝다**가 정확한 진단입니다.

| 영역 | 상태 | 근거 |
|---|---|---|
| 브랜드/디자인 | ✅ 완료 | 'Nedabah Way' 브랜드 정체성, 따뜻한 earth tone, 일관된 톤 |
| 배포 파이프라인 | ✅ 완료 | `main` 푸시 → GitHub Actions 자동 배포, 커스텀 도메인 `nedabah.org`, HTTPS, `.nojekyll` |
| 기본 SEO 위생 | ⚠️ 부분 | `robots.txt`·`sitemap.xml`·canonical·OG·Organization 스키마는 있으나 **단일 페이지 기준** |
| 카테고리 구조 | ❌ 문제 | 프로그램이 모두 `#programs` 앵커 하나에 묶여 **개별 URL이 없음** |
| 검색 인덱싱 | ❌ 미착수 | Search Console/Bing/네이버 서치어드바이저 등록·사이트맵 제출 흔적 없음 |
| 콘텐츠 깊이 | ❌ 부족 | 각 프로그램이 2~3문장. 검색·AI가 인용할 본문 밀도 없음 |
| 전환 장치 | ⚠️ 부분 | 문의 경로(이메일)는 있으나 폼·자동 응대·추적 미연결 |
| 측정 | ❌ 없음 | 애널리틱스/전환 추적 부재 → 효과를 "검증"할 수단이 없음 |

### 1.2 추진율 평가

**현재 홍보 전략 추진율: 약 22 / 100.**

- 기반(브랜드·배포·디자인): 80% 완료 → 잘했습니다.
- 구조(개별 카테고리 분리): 0% → **가장 큰 병목.** 단일 페이지는 검색엔진·AI에게 "주제가 하나"로 읽혀, 여러 프로그램이 서로의 노출을 잡아먹습니다.
- 유통(검색·AI·확산): 5% 미만 → 사실상 미착수.
- 측정(검증): 0% → 무엇이 효과인지 모르는 상태.

### 1.3 핵심 피드백 3가지 (가장 아픈 지적)

1. **"좋은 가게를 골목 안에 숨겨 두었다."** 사이트는 잘 만들었지만, 검색·AI·커뮤니티 어디에도 노출 통로가 없습니다. 만든 것과 알리는 것은 별개입니다.
2. **"여러 개를 1개처럼 홍보하고 있다."** 묵상 모임을 찾는 사람, 청소년 프로그램을 찾는 부모, 기관 워크숍 담당자, AI·자동화를 찾는 실무자는 완전히 다른 검색어를 칩니다. 한 페이지로는 그 어떤 검색어도 1등이 될 수 없습니다. → **이번 작업에서 9개 개별 페이지로 분리 완료(파트 3 참조).**
3. **"검증 수단 없이 달리고 있다."** 측정이 없으면 100점인지 알 수 없습니다. 측정 체계(파트 9)와 평가 루브릭(파트 10·11)부터 깔아야 합니다.

> **이번 PR로 해소된 것:** 카테고리 개별 URL 분리, 페이지별 SEO/구조화데이터, 사이트맵 확장, 내부 링크 재배선. → 추진율 22 → **약 48**로 상승(구조 병목 해소). 나머지는 유통·측정 실행의 몫.

## 2. 전략 목표와 핵심 가설

### 2.1 목표 (SMART)

- **G1 (노출):** 24주 내 9개 카테고리 페이지 전부 Google·네이버에 색인 + 카테고리당 핵심 키워드 3개 이상에서 1페이지 노출.
- **G2 (AI 인용):** ChatGPT·Perplexity·Google AI Overview·네이버 Cue에서 "제주 말씀묵상 모임", "정체성 습관 설계" 등 질의 시 nedabah.org가 인용/언급되는 사례 확보.
- **G3 (유입):** 월간 유기 방문 0 → 24주 차 월 1,000+ (복리 성장 가정).
- **G4 (전환):** 프로그램 문의(모임·코칭·워크숍·자동화) 0 → 월 10건. 노트 정기 독자 확보.
- **G5 (옹호):** 노트·콘텐츠의 자발적 공유(전달) 발생률 측정 가능 상태 + 추천 유입 10%.

### 2.2 핵심 가설 (검증 대상)

| # | 가설 | 검증 방법 |
|---|---|---|
| H1 | 카테고리를 개별 페이지로 분리하면 색인·노출이 는다 | GSC 색인 수·노출수 비교(전/후) |
| H2 | FAQ 구조화데이터가 AI 인용률을 높인다 | AI 검색 수동 질의 + 인용 추적 |
| H3 | "노트(관점·학습) 읽기"가 가장 낮은 진입장벽의 첫 접점이다 | 노트 유입 → 문의 전환율 비교 |
| H4 | 신뢰형 콘텐츠(후기·투명 리포트)가 전환을 끌어올린다 | 후기 게재 전후 전환율 |

> **근거:** 콘텐츠 클러스터를 12개월 이상 지속한 사이트는 단일 페이지 전략 대비 유기 트래픽이 약 40% 높았다는 2026년 보고가 H1을 뒷받침합니다. FAQPage 마크업 페이지의 AI Overview 등장 확률이 약 3.2배라는 보고가 H2를 뒷받침합니다(출처: 파트 12).

## 3. 카테고리 개별 분리 전략 (필러–클러스터)

### 3.1 왜 분리인가 (Why)

2026년 검색·AI 시대의 **1위 랭킹 요인은 '주제 권위(Topical Authority)'**입니다. 특정 주제에 대해 상호 연결된 여러 페이지를 가진 사이트가, 단 하나의 완벽한 페이지를 가진 사이트를 이깁니다. 단일 페이지는 여러 주제로 권위가 분산되어 어느 것도 1위가 못 됩니다. → **허브(필러) 1개 + 카테고리(스포크) 9개 + 향후 클러스터 글 다수** 구조로 전환.

### 3.2 분리 결과물 (What — 이번 PR로 생성됨)

```
/                              (홈 = 브랜드 필러)
/programs/                     (프로그램 허브 = 카테고리 필러, 3개 묶음으로 그룹화)
│  ── 공동체·신앙 ──
├─ /programs/sbm/              (SBM 말씀묵상 모임)
├─ /programs/leadership/       (청소년 리더십 프로젝트)
├─ /programs/iden/             (IDEN 정체성 습관 설계)
│  ── 지식·노트 (퍼널 상단 콘텐츠) ──
├─ /programs/perspective-notes/(관점 노트)
├─ /programs/study-notes/      (학습 노트)
│  ── AI·실행 ──
├─ /programs/ai-lab/           (AI 작업실)
├─ /programs/automation/       (자동화)
├─ /programs/coaching/         (강의·코칭)
└─ /programs/workshop/         (기관 교육·워크숍)
/support/                      (후원·참여·협력)
```

각 페이지 공통 탑재 요소: 고유 `<title>`·메타·canonical·OG, **BreadcrumbList + FAQPage 구조화데이터**, 타깃 페르소나 카드, 단계형 흐름, FAQ, 카테고리 CTA, 형제 카테고리 교차 링크.

|---|---|---|---|
| SBM 모임 | "혼자가 아니라 함께 걷는 주간 묵상" | 제주 말씀묵상 모임, 제주 성경공부 소그룹, 수요 묵상 | 제주 거주, 신앙 정체/번아웃 2030~4050 |

| 후원·협력 | "당신의 자발성이 공동체를 세운다" | 제주 비영리 후원, 신앙공동체 협력 | 후원자·파트너 기관 |

### 3.4 향후 클러스터 글 계획 (각 필러 아래 1,500~2,500자 글로 권위 축적)

- SBM 클러스터: "혼자 큐티가 자꾸 멈추는 이유", "제주에서 작은 신앙 공동체 찾는 법", "묵상–나눔–실천 흐름이란"
- 관점/학습 노트 클러스터(퍼널 상단 SEO 엔진): "관점을 바꾸면 문제가 달라진다", "학습 노트 쓰는 법", "배운 걸 잊지 않는 한 줄 요약법"
- 청소년 클러스터: "아이의 자존감을 키우는 '완주' 경험", "팀 프로젝트가 입시보다 남기는 것"
- AI·자동화 클러스터: "AI 처음 쓰는 사람의 첫 과제", "코딩 없이 반복 업무 자동화하기", "비영리 팀을 위한 AI 활용 첫걸음"
- IDEN·코칭 클러스터: "작심삼일을 끝내는 정체성 기반 습관", "환경을 바꾸면 의지가 필요 없다"

> **권위 규칙:** 필러는 3,000자+, 클러스터는 1,500~2,500자, 모든 클러스터는 자기 필러로 상향 링크하고 필러는 클러스터로 하향 링크(허브앤스포크). 20개의 상호 연결 글이 단일 5,000자 글을 이깁니다.

## 4. 검색·AI 노출 최적화 (SEO + GEO/AEO + 네이버)

### 4.1 기술 SEO 체크리스트 (무료)

- [x] 페이지별 고유 title/description/canonical/OG
- [x] BreadcrumbList + FAQPage 구조화데이터 (이번 PR)
- [x] WebSite + ItemList 구조화데이터(홈), Organization 엔티티 고정
- [x] `robots.txt`에 AI 크롤러(GPTBot·ClaudeBot·PerplexityBot·Google-Extended 등) 명시 허용
- [x] 사이트맵에 12개 실제 페이지 URL 등재, `robots.txt`에서 사이트맵 선언
- [x] 404 페이지(이탈 보존·내부 링크 복귀)
- [ ] Google Search Console 등록 + 사이트맵 제출 + 색인 요청
- [ ] Bing Webmaster Tools 등록(= ChatGPT/Copilot 노출 기반)
- [ ] 네이버 서치어드바이저 등록 + 사이트맵 제출
- [ ] Core Web Vitals 점검(정적 사이트라 유리), 이미지 추가 시 lazy-load
- [ ] 모바일 가독성·탭 타깃 점검

### 4.2 GEO/AEO — AI가 인용하게 만들기

검증된 2025~2026 실무에서 도출한 규칙:

1. **답변 우선 구조(Answer-first):** 각 페이지·문단 상단에 질문에 대한 40~60단어 직답을 두고, 그 아래 근거(통계·예시·인용)를 배치. → 우리 FAQ가 이 형태.
2. **FAQPage 스키마 전면 적용:** FAQ 마크업 페이지는 AI Overview 등장 확률 약 3.2배, 인용률 약 41% vs 15%. → 9개 카테고리 전부 적용 완료.
3. **엔티티 명확화:** 페이지당 1차 엔티티 1개 + 보조 엔티티 3~6개. Organization 스키마로 "Nedabah Way"를 단일 엔티티로 고정(파편화 방지).
4. **E-E-A-T 신호:** 운영 주체·주소·연락·실제 활동 기록을 노출. 검증 가능한 데이터·후기를 footnote 형태로.
5. **멀티엔진 분산:** ChatGPT는 위키/권위, Perplexity는 커뮤니티(카페·오픈 게시판), Bing은 구조화 FAQ, 네이버 Cue는 영수증·실사용 후기형 콘텐츠를 선호 → 채널을 나눠 공략(파트 8).

### 4.3 네이버 최적화 (한국 타깃 필수)

- **C-Rank(창작자 신뢰):** 한 채널을 **오래·꾸준히·한 주제로** 운영해야 점수가 쌓임 → 네이버 블로그를 "제주 신앙공동체/묵상" 단일 주제로 주 1~2회 연재.
- **D.I.A.+(검색의도):** 키워드 도배 금지. "검색 의도에 정확히 답하는" 실사용·후기형 글이 상위.
- **Cue(생성형 AI):** 검증 가능한 데이터·실제 후기·영수증형 진정성 콘텐츠 우대, 도배·반복 배제.
- 실행: 블로그 글 말미에 항상 해당 카테고리 페이지로 1링크(자연스러운 "더 알아보기").

## 5. 9단계 심리 흐름 설계

사람을 "조종"하는 것이 아니라, **필요한 사람이 자기 속도로 다음 칸으로 넘어가도록 마찰을 줄여 주는** 흐름입니다. 각 단계마다 심리·콘텐츠·CTA·측정·윤리 가드레일을 정의합니다.

| 단계 | 심리 상태 | 우리가 줄 것 | 채널/콘텐츠 | 다음 칸 CTA | 측정 지표 |
|---|---|---|---|---|---|
| 1. 무인지 | 우리를 모름 | — | 검색·공유 노출 자체 | (노출) | 노출수(Impressions) |
| 2. 인지 | 우연히 발견 | 첫인상 한 줄 | 검색 스니펫·OG 카드 | 클릭 | CTR |
| 3. 흥미 | "어 멈칫" | 곱씹을 한 문장 | 관점·학습 노트, 한 줄 카드 | 더 읽기 | 체류시간·스크롤 |
| 4. 공감 | "내 얘기다" | 페르소나 거울 | "이 길이 필요한 사람" 카드 | 카테고리 탐색 | 페이지/세션 |
| 5. 신뢰 | "믿어도 될까" | 투명성·후기·주체 명시 | FAQ, 후원 리포트, 주소·연락 | 문의 고려 | FAQ 펼침·후기 조회 |
| 6. 탐색 | "나에게 맞나" | 비교·선택 도움 | 프로그램 허브 "어떤 길이 맞나" | 선택 | 내부 이동 경로 |
| 7. 첫 행동 | 작은 결심 | 가장 낮은 문턱 | **노트 소식/모임 가볍게 문의** | 문의 완료 | 문의 전환율 |
| 8. 참여/습관 | 관계 시작 | 지속의 리듬 | 노트 정기 구독 → 모임/코칭/워크숍 | 참여·재방문 | 재방문율·문의수 |
| 9. 옹호/전파 | "남에게도" | 전달할 자산 | "떠오르는 사람에게" 공유 카드 | 추천·공유 | 추천 유입·공유수 |

**핵심 설계 원칙**
- **마이크로 전환 우선:** 9단계를 한 번에 건너뛰게 강요하지 않음. 7단계(가벼운 문의)가 모든 길의 공통 첫 행동.
- **각 카테고리 페이지가 작은 9단계를 자체 완결:** 히어로(2·3) → 페르소나(4) → FAQ/주체(5) → 비교 링크(6) → CTA(7).
- **되돌아갈 출구 항상 제공:** 부담되면 "먼저 관점·학습 노트부터 읽기"로 후퇴 가능 → 이탈 대신 보존.

## 6. 대상(타깃) 선정과 자연 확산 설계 + 윤리 가드레일

> 사용자 요청의 "꼭 필요한 대상과 그 가족·연관자에게 대놓고 드러내지 말고 자연스럽게 안내" → 이를 **정직한 인바운드(소프트) 마케팅**으로 구현합니다. 강매·기만이 아니라, *필요한 사람이 스스로 발견하고, 신뢰하는 사람을 통해 전해 받게* 설계합니다. 이 방식이 네이버 C-Rank·Google E-E-A-T·AI 인용 모두에서 더 강합니다.

### 6.1 타깃 선정 (ICP — Ideal Community Profile)

1. **제주 거주 신앙 정체층** (SBM·IDEN) — 검색 의도가 명확해 가장 전환이 빠름.
2. **청소년 자녀를 둔 부모/교사** (리더십) — 본인이 아니라 **가족을 위해** 찾는 대표적 케이스. "자녀의 완주 경험"이라는 부모의 언어로 안내.
3. **기관 교육 담당자** (워크숍) — B2B2C. 담당자가 도입하면 다수 참여자에게 자연 확산.
4. **자기 방향을 다시 세우려는 자기계발층** (IDEN·강의·코칭·관점/학습 노트).
5. **AI·자동화로 시간을 아끼려는 1인·소상공인·기관 실무자** (AI 작업실·자동화).

### 6.2 "자연스러운 안내" = 정직한 확산 메커니즘

- **검색 발견형:** 그들이 실제로 치는 검색어에 정확히 답하는 페이지를 둔다(파트 3·4). 광고가 아니라 답으로 만난다.
- **선물/전달형 자산:** 관점·학습 노트 카드에 "이 글이 떠오르는 사람에게 전해주세요" 공유 버튼. 발신자는 지인 → 신뢰 기반 도달(가족·지인 연관 확산). 단, **수신자에게 강제 등록·자동 수집 없음.**
- **공유 가능한 무료 자산:** 묵상 카드, 워크시트 PDF, 짧은 인용 이미지 → 퍼가기 쉬움 → 유기 확산.
- **부모→자녀, 담당자→구성원의 자연 경로:** 의사결정자(부모·담당자)의 언어로 페이지를 쓰되, 실제 수혜자(자녀·구성원)에게는 본인 동의로 연결.

### 6.3 윤리 가드레일 (반드시 지킴 — 위반 시 신뢰·SEO 동반 붕괴)

- ❌ 가짜 후기·자작 댓글·사칭 계정(astroturfing) 금지. ✅ 실명·실제 활동 기반 콘텐츠만.
- ❌ 슬픔·불안 등 취약 심리를 표적해 압박하는 카피 금지. ✅ 필요를 비추되 선택은 본인에게.
- ❌ 동의 없는 이메일/연락처 수집·제3자 등록 금지. ✅ 명시적 동의 + 1클릭 수신거부.
- ❌ "대놓고 숨기는" 기만적 위장 광고 금지. ✅ 발신 주체(네다바웨이)를 항상 밝히는 투명한 소프트 안내.
- ✅ 미성년 대상은 보호자 동의 경로를 우선.

> 이 가드레일은 제약이 아니라 **전환 엔진**입니다. 신뢰(5단계)가 무너지면 9단계 흐름 전체가 끊깁니다.

## 7. 24단계 실행 로드맵 (0~24주)

4개 국면(Phase) × 단계. 각 단계는 "산출물 + 검증"으로 끝나야 완료.

### Phase 0 — 기반·계측 (1~6주)
1. **카테고리 개별 페이지 분리 배포** ✅(이번 PR) — 검증: 12개 페이지 URL(홈+허브+9개 카테고리+후원) 200 응답.
2. **Google Search Console 등록 + 사이트맵 제출** — 검증: 색인 커버리지(전 URL).
3. **Bing Webmaster + 네이버 서치어드바이저 등록·제출** — 검증: 양쪽 색인 시작.
4. **무료 애널리틱스 연결**(GA4 또는 경량 대안) + 전환 이벤트(문의·노트 구독) 정의 — 검증: 실시간 수집 확인.
5. **구조화데이터 검증**(Rich Results Test) — 검증: FAQ/Breadcrumb 오류 0.
6. **키워드 맵 확정**(9개 카테고리×핵심 3 키워드) — 검증: 표 완성.

### Phase 1 — 콘텐츠 권위 (7~13주)
7. 각 필러 본문 3,000자+로 보강(현 페이지 확장).
8. 카테고리당 클러스터 글 1편씩 작성·발행(관점·학습 노트를 퍼널 상단 SEO 엔진으로 우선 가동). ✅(9편 전부 발행: SBM·청소년 리더십·IDEN·관점 노트·학습 노트·AI 작업실·자동화·강의코칭·기관 워크숍 — 책/논문 근거+사실검증+검수기준 적용)
9. FAQ 각 페이지 6문항 이상으로 확장(AEO 강화).
10. 관점·학습 노트 아카이브(목록) 페이지 신설(콘텐츠 자산화·내부 링크 허브).
11. 실제 참여자 후기 3건 수집·게재(동의 하에, 실명/익명 선택).
12. 공유용 묵상 카드/워크시트 PDF 3종 제작.
13. 내부 링크 감사(필러↔클러스터 양방향 점검).

### Phase 2 — 확산 (14~20주)
14. 네이버 블로그 개설, 단일 주제 주 1~2회 연재 시작(C-Rank 적립).
15. 관련 커뮤니티/카페/오픈채팅에 **가치 우선** 참여(스팸 금지, 가드레일 준수).
16. 노트 공유 카드에 "전달하기" 도입 → 지인 확산 측정. ✅(공유 바: X·페이스북·메일·링크복사·네이티브 공유 — 전 카테고리 페이지 자동 적용)
17. 지역·기관 파트너 3곳에 협력 제안(워크숍 레퍼럴).
18. 게스트 글/인터뷰 1건(외부 백링크 확보).
19. 인스타/스레드 등 무료 소셜에 한 줄 카드 정기 게시.
20. 노트 구독·문의 시 환영 안내(자동 1통) 설계.

### Phase 3 — 최적화·복리 (21~24주)
21. AI 인용 추적(주요 질의 수동 점검) → 누락 갭 보강.
22. 전환 A/B(문의 CTA 문구·위치) 1회 실험.
23. 분기 성과 리포트 작성(후원자·내부 공유) — 투명성=신뢰 자산.
24. 다음 분기 키워드/클러스터 재계획(루프 반복).

> **로드맵 운용 원칙:** 단계는 순서가 있지만 1~6은 1주 차에 몰아쳐도 됨. 핵심은 "측정(2·4)을 콘텐츠(7~)보다 먼저" 까는 것.

- **주간 리뷰:** 매주 루브릭(파트 10·11) 자가 채점 → 점수 추세로 진척 확인.
