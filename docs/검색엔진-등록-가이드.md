# 검색엔진 등록·색인 가이드 (5분, 무료)

> 카테고리 분리·구조화데이터·사이트맵은 **이미 코드에 완료**되어 있습니다.
> 이 문서의 단계는 "검색엔진에 우리 사이트를 켜는" 마지막 스위치이며,
> **계정 로그인·소유확인이 필요해 사이트 주인이 직접** 해야 하는 부분입니다.
> (대신, 받은 인증코드를 알려주시면 코드 반영은 제가 해드립니다.)

---

## 0단계 — 먼저 배포부터 (필수)

새로 만든 9개 카테고리 페이지는 **`main` 브랜치에 병합돼야** `nedabah.org`에 실제로 뜹니다.
(배포는 `main` push 시 자동) → **PR #10을 merge** 한 뒤 1~2분 기다렸다가 아래를 진행하세요.

확인: 브라우저에서 `https://nedabah.org/programs/` 가 열리면 OK.

---

## 1단계 — Google Search Console (구글 + AI Overview 기반)

1. https://search.google.com/search-console 접속 → 로그인
2. 속성 추가 → **URL 접두어** 선택 → `https://nedabah.org/` 입력
3. 소유확인 방법 중 **HTML 태그** 선택 → `content="..."` 안의 **코드값 복사**
4. 그 값을 → `index.html`의 아래 줄에 붙이고 주석(`<!-- -->`)을 풀기
   ```html
   <meta name="google-site-verification" content="여기에-구글-인증코드">
   ```
   → 커밋·`main` push (또는 **그 코드값만 저에게 주세요. 제가 넣어드립니다.**)
5. 배포 후 Search Console에서 **확인** 클릭
6. 좌측 **Sitemaps** → `sitemap.xml` 입력 → 제출
7. 주요 페이지는 상단 검색창에 URL 넣고 **색인 생성 요청**

## 2단계 — Bing Webmaster Tools (ChatGPT·Copilot 노출 기반)

1. https://www.bing.com/webmasters 접속 → 로그인
2. **Import from Google Search Console** 선택 → 1단계로 끝난 속성을 그대로 가져오기(가장 빠름)
   - 또는 사이트 추가 후 `sitemap.xml` 제출
3. Bing 색인은 ChatGPT/Copilot 같은 AI 검색 인용의 토대가 됩니다.

## 3단계 — 네이버 서치어드바이저 (한국 검색·Cue 필수)

1. https://searchadvisor.naver.com 접속 → 로그인
2. **웹마스터 도구** → 사이트 등록 → `https://nedabah.org/` 입력
3. 소유확인 **HTML 태그** 선택 → 코드값 복사 → `index.html`의 아래 줄에 붙이고 주석 풀기
   ```html
   <meta name="naver-site-verification" content="여기에-네이버-인증코드">
   ```
   → 커밋·push (또는 **코드값만 주시면 제가 반영**)
4. 확인 후 **요청 → 사이트맵 제출**: `https://nedabah.org/sitemap.xml`
5. **요청 → 웹페이지 수집**: 주요 카테고리 URL 직접 수집 요청

---

## 4단계 — (선택) 방문·전환 측정 켜기

효과를 "검증"하려면 측정이 필요합니다(전략 문서 파트 9).

- **Google Analytics 4**: https://analytics.google.com 에서 측정 ID(`G-XXXXXXX`) 발급
  → 그 ID를 알려주시면 전 페이지에 추적 스니펫을 넣어드립니다.
- 문의 폼 자동 수집: **Formspree 무료 티어** 엔드포인트 발급 →
  알려주시면 문의/구독 폼에 연결해 드립니다.
