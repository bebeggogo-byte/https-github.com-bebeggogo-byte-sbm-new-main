# 디자인 레퍼런스와 결정 (2026-11-13, 디자인 v2)

## 1. 참고한 자료
| 자료 | 확인한 내용 | 적용 |
|---|---|---|
| 토스 디자인 시스템 소개(oppadu 디자인 시스템 갤러리) | Pretendard 서체, 단일 파란색 강조, 한 화면에 한 가지 행동 | 서체를 Pretendard로 변경. 강조색은 파랑 1개. 화면마다 주 버튼 1개 |
| 토스 UX 라이팅 인터뷰(toss.im/tossfeed) | 제품 안 모든 문구의 어조 통일 | 사실 명시 문장으로 통일(docs/글쓰기-검수기준.md) |
| 랜딩 페이지 가이드(landerlab, learnybox, klientboost 등 업체 자료) | 첫 화면에 제안과 주 버튼 1개, 신뢰 요소 배치 | 첫 화면에 제목, 설명, 1분 신청만 둠 |
| 폼·팝업 조사(HubSpot, NP Digital, Smashing Magazine) | 입력 칸 최소화. 모바일 전면 팝업은 구글 불이익 | docs/사이트-리뉴얼-리서치와-구조.md 참조 |

조사 한계: 여백과 글자 크기에 관한 학술·NN/g 자료는 검색에서 확보하지 못했습니다. 위 자료는 실무 가이드 수준입니다.

## 2. 결정한 규칙
- **배경**: 흰색(#fff)과 연회색(#f5f6f8) 두 가지만 씁니다. 그라데이션, 점 패턴, 원형 장식, 베이지 배경은 쓰지 않습니다.
- **색**
  - 글자: #191f28
  - 보조 글자: #4e5968, #8b95a1
  - 선: #e5e8eb
  - 강조: 파랑 #2f6bff 1개
  - 금색은 쓰지 않습니다. 빨강은 마감 표시에만 씁니다.
- **서체**: Pretendard. 숫자와 제목은 굵게(800), 본문은 보통(400~500).
- **장식**: 그림자, 기울인 도장, 이모지, 큰따옴표 장식을 쓰지 않습니다.
- **인용문**: 따옴표 없이 "컨설턴트의 말" 라벨, 큰 글자, 왼쪽 파란 선, 이름을 넣습니다.
- **강조 방식**: 핵심 단어만 파란색으로 강조합니다. 한 문단에 2곳 이내로 씁니다.
- **홍보 이미지**: 흰 배경, 검은 큰 글자, 파란 강조, 연회색 가격 상자, 하단 선과 주소.
- **기관 표기**: 로고 대신 머리글자 타일을 씁니다.

## 3. 적용 범위
- 아우라토 페이지(홈, 컨설팅 안내, 진행 과정, 국시 직후, 지원 기관, 개인정보)와 오른쪽 바로가기 바
- 홍보 이미지 5종(og/consulting, promo-1080x1350, after-exam, after-exam-1080x1350, quote-1080x1350)
- 네다바웨이 하위 페이지(커피색 계열 기존 디자인)는 아직 적용하지 않았습니다.

## 4. 새 구성 요소를 만들 때의 순서
1. 이 문서의 규칙으로 만들 수 있는지 먼저 확인합니다.
2. 규칙에 없는 형태가 필요하면 참고 자료를 찾아 1번 표에 추가한 뒤 만듭니다.
3. 숫자가 들어가면 `python3 tools/check-numbers.py`를 실행합니다.
