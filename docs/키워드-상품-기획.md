# 아우라토 키워드: 단독 상품 테스트 기획 (2026-11-13)

## 1. 개념
- **한 줄 설명**: 내 경험에서 반복해 나오는 핵심가치 단어 3개와 강점 단어 3개를 뽑아, 자기소개서와 면접에서 같은 키워드를 쓰게 하는 방법.
- **차별점**: 다른 지원자와 비교한 우열이 아니라 본인 경험에서 나온 단어를 씁니다(컨설턴트의 말: "경쟁이 아닌 나만의 특성").
- **퍼지게 만드는 장치**: 결과가 "키워드 카드" 이미지 한 장으로 나옵니다. 저장하고 공유하기 쉬운 형태입니다. 카드에 이름이나 학교가 들어가지 않습니다.

## 2. 이번에 만든 것(테스트 단계)
- `/keyword/` 무료 자가 테스트
  - 경험 3~5개를 입력하고, 경험마다 핵심가치·강점 단어를 2개까지 고릅니다.
  - 결과: 키워드 3개씩, 자기소개 첫 문장 초안, 카드 이미지 저장, 테스트 링크 공유.
  - 입력 내용은 브라우저 안에서만 계산하고 서버로 보내지 않습니다.
  - 단어 목록 32개(핵심가치 16, 강점 16)는 NCS 직업기초능력과 VIA 성격강점 분류를 참고했습니다.
- **키워드 분석 사전 신청 폼**: 컨설턴트가 직접 뽑는 유료 "키워드 분석"(화상 60분 1회 + 키워드 요약 보고서)의 수요를 확인합니다.
  - 가격은 표시하지 않고 "사전 신청자에게 먼저 안내"로 두었습니다.
  - 신청은 Notion 접수 DB에 "키워드 분석 단독 상품 사전 신청"으로 들어옵니다. 자가 테스트 결과 키워드가 메모에 함께 기록됩니다.
- 홈 안내 섹션, 오른쪽 바 "키워드" 버튼, 링크 미리보기 이미지(og/keyword.png).

## 3. 테스트 기준(12월 31일까지)

| 지표 | 확인 방법 | 단독 상품으로 진행하는 기준 |
|---|---|---|
| 사전 신청 수 | Notion 접수 DB 주제 필터 | 20건 이상 |
| 사전 신청 중 결제 전환 | 가격 안내 문자 후 입금 | 30% 이상 |
| 2회 과정으로 이어진 수 | Notion에서 같은 이름 대조 | 참고 지표 |
| 테스트 완료 수, 카드 저장 수 | GA4 필요(현재 측정 불가) | GA4 ID 확보 후 측정 |

- 기준에 미달하면 키워드 테스트는 2회 과정의 유입 도구로만 씁니다.

## 4. 단독 상품안(대표 결정 필요)

| 항목 | 안 |
|---|---|
| 이름 | 아우라토 키워드 분석 |
| 구성 | 사전 자료 제출 → 화상 60분 1회 → 키워드 요약 보고서(핵심가치 3, 강점 3, 근거 경험, 1분 자기소개 첫 3문장) |
| 권장 가격 | 9만원(시중 1:1 코칭 1회 7만~15만원 범위) |
| 2회 과정과의 관계 | 키워드 분석 구매자가 2회 과정을 신청하면 차액만 결제 |
| 대상 확장 | 병원 직종 외 대학 저학년, 이직 준비자, 임용·공무원 면접 준비자 |

## 5. 알리는 방법
1. 인스타: 가상 지원자의 키워드 카드를 예시로 게시하고 "내 키워드 3개는?" 테스트 링크를 붙입니다.
2. 학과 단톡: 학생이 자기 카드를 공유합니다. 카드에 개인정보가 없어 부담이 적습니다.
3. 학교 제안: 비교과 특강 "나의 키워드 찾기"(60분, 단체)로 제안하고, 개별 분석은 1:1로 연결합니다.
4. 시험 달력과 연결: 시험 전 기간에는 컨설팅 대신 3분 테스트를 권하고, 시험 후 컨설팅으로 연결합니다.

## 6. 상표
- "아우라토 키워드"는 아우라토 상표(제41류 출원) 범위에서 서비스명으로 씁니다. 방법 자체(단어 집계)는 독점할 수 없으므로 이름, 카드 형식, 컨설턴트 분석으로 구별합니다.
