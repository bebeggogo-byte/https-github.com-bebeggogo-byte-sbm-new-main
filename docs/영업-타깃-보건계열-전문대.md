# 영업 타깃: 4년제 간호학과를 둔 2·3년제 전문대학 (내부용, 2026-11-03)

> 공개하지 않는 내부 영업 자료입니다. 사이트에는 학교 이름을 올리지 않습니다.

## 왜 이 학교들인가

- **전체 규모**: 교육부 자료 기준으로 4년제 간호학과(학사학위과정)를 둔 전문대학은 **83개교**입니다.
  - 2024학년도 「학사학위과정 간호과 지정현황」 기준입니다.
  - 원문 첨부파일은 이 환경에서 접속이 막혀 열지 못했습니다(moe.go.kr).
- **학과 구성**: 이 학교들은 간호학과 옆에 임상병리·방사선·물리치료·작업치료·치위생·응급구조·보건행정 학과를 함께 두는 경우가 많습니다.
  - 그래서 한 학교에 들어가면 보건계열 여러 학과로 넓힐 수 있습니다.
- **예산**: 전문대학 혁신지원사업 「Learning 5.0 취창업 학생지원 프로그램」 같은 비교과 예산이 있습니다.
  - 지금 운영 중인 한라대(13명)와 같은 구조입니다.

## 실적 정리 양식: 대표가 코칭한 학생의 합격처

사이트에 올릴 때는 **학생 이름, 학교 이름, 연도별 개인 식별 정보를 빼고** 기관 유형과 직종만 씁니다.
- 예: "상급종합병원 간호사 ○명"

| 연도 | 학교(내부용) | 직종 | 합격 기관 | 기관 유형 | 공개 동의 |
|---|---|---|---|---|---|
| | | 간호사 / 임상병리사 / … | | 상급종합병원 / 대학병원·종합병원 / 국가·공공기관 | 예·아니오 |

- **기관 유형 기준**
  - 상급종합병원: 보건복지부 지정. 제5기 2024~2026년 47곳. 2027년부터 제6기
  - 대학병원·종합병원: 대학 부속병원과 종합병원
  - 국가·공공기관: 국립대병원, 국립중앙의료원, 국립암센터, 보훈병원, 근로복지공단 병원, 국민건강보험 일산병원, 지방의료원, 보건직·간호직·의료기술직 공무원
- **공개 방법**: 이 표가 채워지면 /consulting/ 과 /colleges/ 에 **"합격 기관 유형별 실적"** 블록을 추가합니다.
  - 숫자와 기관 유형만 표시합니다.
  - 기관명은 학생 동의가 있을 때만 씁니다.
