# 시장조사 · 거래처 리스트 (2026 하반기)

강사 확장을 위한 조사 결과. 우선순위 순서대로 접근한다.

---

## 1. 업계 상황 — 순풍 3가지

1. **AI 교육 수요 폭발**: 2026년 정부 AI 예산 **9.9조 원(전년의 약 3배)**, 41개 부처 741개 사업.
   공공·복지기관마다 "AI 역량교육"을 해야 하는 압박이 생겼는데, 지방에는 실사용 기반 강사가 희소.
   → 대표님의 **AI활용(종사자 업무·참여주민 생활)** 상품은 지금이 최적기.
2. **자활 생태계는 전국망**: 광역자활센터 **16개 시·도** + 지역자활센터 **전국 250개**.
   제주 광역 실적(4개 센터 40시간)은 타 시·도 광역센터에 통하는 명함이다.
3. **예산 사이클**: 공공기관은 8~10월에 내년 계획·예산을 짠다. **지금이 내년 연간 계약의 골든타임.**

## 4. 실행 순서

1. **이번 주**: Tier 1 문자+제안서 발송 (문자 끝에 "혹시 주변 기관에도 필요하면 전달 부탁드립니다" 한 줄)
2. **8월 안**: Tier 3 강사 등록 2건 (평생교육 강사뱅크, 인재개발원 문의)
3. **답장 오는 대로**: 기관 맞춤판 제안서 (제작: 클로드)
4. **9월**: Tier 2 직접 제안 시작
5. **10월~**: 제주 실적 업데이트 후 Tier 4 (육지 광역) 발송
