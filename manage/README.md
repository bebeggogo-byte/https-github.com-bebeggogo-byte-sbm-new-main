# 운영 관제 센터 (`/manage/`)

온라인 강의 운영을 **하나의 화면**에서 통제하는 관리자용 도구입니다.
접수 → 수강생 데이터 → 세그먼트(분류) → 출석 → 메시지/설문 이 운영 순서대로 연결됩니다.

> 접속: `https://nedabah.org/manage/` (검색 색인 제외 · 관리자 전용)

## 무엇을 하나요

| 탭 | 하는 일 |
|----|--------|
| **대시보드** | 총 수강생·확정·대기·출석률 KPI, **신청 강좌 수 분포**(예: "1개만 신청" 몇 명 / "3개 신청" 몇 명), 강좌별 인원, 다가오는 회차 |
| **접수·수강생** | 신청자 등록/수정/삭제, 강좌 복수 배정, 상태(신청·확정·대기·취소), 태그·메모, 검색·필터, CSV 내보내기 |
| **강좌·회차** | 강좌(6개 예시, 개수 제한 없음)와 회차 일정 관리, 정원. 각 강좌 카드의 **📋 이 강좌 출석부 열기** 버튼으로 해당 강좌 출석부로 바로 이동 |
| **출석부** | 상단 **강좌 클릭 버튼**(색상·인원)으로 강좌별 출석부를 개별 전환 → 신청자 이름 목록 + 출결 체크(출석·지각·결석·공결), 누적 출석률 자동 집계, **인쇄** 가능, CSV |
| **세그먼트** | 조건으로 대상 자동 추출 — "1개만 신청", "3개 이상", "특정 강좌 미신청", "결석 2회 이상", 상태·태그 조합 → 메시지로 전달 |
| **수료** | 출석률 기준(기본 80%) **자동 수료 판정** → 수료증 인쇄/PDF(공결은 출석 인정) |
| **메시지·설문** | 문의·안내·리마인드·**종료 후 설문**·**입금 안내** 템플릿 + 변수 자동치환(`{이름}`,`{강좌명}`,`{강좌목록}`,`{날짜}`,`{미납액}`,`{설문링크}`…) → 문자앱 열기 / 카톡 공지 복사 / 대량발송 CSV |
| **재무·정산** | 수강료 **입금/미수금**, 강좌별 정산(청구·수납), 수입·지출 장부, **프리랜서 3.3% 원천징수 계산기**, 미납자 → 입금 안내 메시지 연결 |
| **후원** | 정기·일시 **후원자 관리**, 월 정기·누적 수령 집계, 후원 중단 팔로업, **감사 메시지** 발송 |
| **문의** | 인스타 DM·카톡·메일 **문의 인박스**(신규·진행·완료), 미응답 알림 |
| **할일** | 회차·정산·마감 **할일 + D-day**, 회차·기한을 합친 **운영 캘린더** 타임라인 |
| **데이터** | 기관명·대표자·설문링크·**수료 기준·화면 잠금 PIN** 설정, 전체 백업(JSON), 구글폼 **CSV 가져오기**, 샘플 불러오기 |

> 실명·연락처·후원 정보를 다루므로 **데이터 탭에서 PIN을 설정**하면 접속 시 잠금 화면이 뜹니다. 수강생에는 **개인정보 수집·이용 동의** 필드가 있고, 대시보드가 미동의자를 알려 줍니다.

## 운영 흐름 (유기적 연결)

```
[구글폼 접수] → CSV 가져오기 → 접수·수강생 ──┐
                                            │ (수강료·동의 입력)
             강좌·회차 설정 ────────────────┤
                                            ▼
                            출석부(회차별 출결) → 결석/출석률 자동 집계
                                            │              │
                                            │              ▼
                                            │           수료(자동 판정)→수료증
                                            ▼
   세그먼트(1개/3개 신청·결석 2회+·미납자 …) ──▶ 메시지·설문
                                            │      문자앱/카톡공지/대량 CSV
                                            ▼
                            재무·정산(미수금)──▶ 입금 안내 메시지
   후원 ──▶ 감사 메시지     문의 인박스     할일·캘린더(회차·정산·마감)
   ↑ 재무·후원·수강료 → 대시보드 KPI(이번 달 수입·미수금)와 알림으로 환류
```

## 데이터 저장

서버가 없는 **정적 사이트**라 데이터는 접속한 **브라우저(localStorage)에만** 저장됩니다.
- 기기·브라우저가 바뀌면 데이터가 없습니다 → **데이터 탭 → 전체 백업(JSON)** 을 주기적으로 내려받으세요.
- 여러 사람이 같은 데이터를 공유하려면 아래 "실제 자동화로 확장" 참고.

## 실제 "자동 발송"으로 확장하기

이 도구는 **대상·문구 조립까지** 자동화합니다. 버튼 없이 완전 자동 발송하려면 외부 서비스가 필요합니다.

- **문자(SMS/LMS)**: 네이버 클라우드 SENS · 알리고 · 뿌리오 등.
  메시지 탭의 **대량발송 CSV**(이름·연락처·개인화문구)를 업로드하거나, 각 서비스 API로 자동 발송.
- **카카오 알림톡**: 카카오 비즈메시지(사업자 등록·템플릿 사전 심사 필요) → 발송 API.
- **카톡 오픈채팅 공지**: 공식 자동화 API가 없어 **공지 문구 복사 → 붙여넣기**가 현실적.
- **접수 자동 수집**: 구글폼 → 구글시트 → 시트를 CSV로 내보내 이곳에 가져오기.
  구글시트 + Apps Script로 정기 알림/집계까지 자동화 가능.
- **다인 공유·영구 저장**: 백엔드(예: Google Sheets API, Firebase, Supabase)를 붙이면
  localStorage 대신 공유 DB로 운영할 수 있습니다. 이 프론트엔드의 데이터 모델(`app.js`의
  `students / courses / attendance / templates`)을 그대로 API에 매핑하면 됩니다.

## 기술

순수 HTML/CSS/Vanilla JS · 빌드 없음 · localStorage · CSV 파서 내장.
사이트의 마케팅 페이지 스타일과 독립된 `manage.css`를 사용합니다.
