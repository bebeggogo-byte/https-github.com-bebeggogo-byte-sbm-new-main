# 강의 스튜디오 (Lecture Studio)

강의를 **녹음 → 원자화 → 조립**하는 개인용 설치형 웹앱(PWA).
백엔드 없이 브라우저 안에서만 동작하며, 컴퓨터와 폰에 각각 설치해 오프라인으로 쓸 수 있습니다.

주소: `https://nedabah.org/studio/`

## 무엇을 하나
현장에서 무선마이크로 강의하는 소리를 노트북 마이크로 **녹음**하고, 지원 브라우저(크롬·엣지·안드로이드)에서는 **실시간 자막**을 함께 기록합니다.
그 원본을 **클로드로 원자화**해 "지식 아톰"(개념·정의·사례·예화·비유·통계·인용·질문·적용·실천·반론·전환)으로 쪼개 저장·분류하고,
나중에 원하는 주제의 새 강의로 **조립·조합·융합**합니다.

## 흐름
0. **설계 (강의 전)** — 슬라이드를 가져와 유도하고 있는 설계 방향을 읽어내고 깊이를 더합니다.
   - `.pptx` 파일을 그대로 가져오면(외부 라이브러리 없이 브라우저에서 해체) 슬라이드별 텍스트 + 발표자 노트가 자동 추출됩니다. 또는 개요를 붙여넣기.
   - **내 설계 의도**를 쓰고 `① 심화 설계 프롬프트` → 클로드 → `② 결과 붙여넣기` 하면 **설계 보드**가 생성됩니다:
     전체 흐름 리딩 · 유도 방향 · 얕게 머무는 지점, 구간마다 심화 통찰 / 찌르는 질문 /
     깊이 있는 얻음을 만드는 활동 가이드 / 전환 문장 / **실존하는 책 인용구**(지어내기 금지 규칙),
     마무리의 깊은 얻음·결단까지. `.md`로 내보내 강의 노트로 사용.
   - **🖼 슬라이드 초안(.pptx)**: 설계 보드를 브라우저가 직접 .pptx로 만들어 저장합니다(외부 서비스 불필요).
     PowerPoint·키노트·구글슬라이드에서 열어 다듬으면 됩니다. 조립대에서도 조립본 → .pptx 가능.
   - **NotebookLM 연동(수동)**: `.md` 내보내기 파일을 NotebookLM에 드래그해 소스로 올리고,
     NotebookLM이 만든 브리핑·정리는 슬라이드 개요 칸에 붙여넣어 다시 심화 설계에 쓰세요.
     (NotebookLM은 공식 API가 없어 직접 연결 대신 파일로 오갑니다.)
   - [녹음] 탭에서 설계를 연결하면 제목·주제·의도가 자동으로 채워지고, 원자화 때 설계 의도가 반영됩니다.
1. **녹음** — 제목·주제·태그·메모 입력 후 녹음. 실시간 자막이 쌓입니다.
   - 강의 중 **마커**(💡핵심·📖예화·❓질문·🔁다시 쓸 것)를 원탭으로 찍으면 원자화 때 우선 반영됩니다.
   - 녹음 조각을 1초 단위로 저장해 **브라우저가 죽어도 다음 실행 때 복구**를 제안합니다.
   - Wake Lock으로 녹음 중 화면 꺼짐을 막습니다(지원 기기).
   - 폰 기본 녹음앱으로 녹음했다면 [강의원본] → **＋ 오디오 파일**로 가져올 수 있습니다.
2. **강의원본** — 저장된 녹음/자막을 확인·편집.
   - **교정**: 발음·소음으로 잘못 받아쓴 단어를 클로드가 문맥으로 유추해 바로잡습니다.
     `① 교정 프롬프트 복사` → 클로드 → `② 교정본 붙여넣기`. 원문은 자동 보관되고 언제든 복원 가능.
3. **원자화** — `① 프롬프트 복사` → 클로드에 붙여넣기 → 나온 JSON을 `② 붙여넣기` 하면 아톰이 자동 생성·분류됩니다.
   (설정에 Anthropic API 키를 넣으면 `⚡ 자동 원자화`도 가능)
4. **아톰** — 검색·유형·주제·태그로 분류/편집. `🧹 중복 정리` 프롬프트로 라이브러리 위생 관리.
   각 아톰에는 **사용 이력**이 기록되어 같은 예화를 같은 청중에 반복하는 일을 막아 줍니다.
5. **조립대** — **주제를 입력하면 소스에서 조합**합니다.
   - `🔎 관련 아톰 추천`: 이 기기에서 키워드로 즉시 후보 검색(한국어 조사 대응).
   - `📇 클로드 선택 프롬프트`: 아톰 카탈로그 전체를 클로드에 보여 조합·순서·역할까지 골라 받고,
     주제에 필요하지만 소스에 없는 **부족한 내용(갭)** 도 제안받습니다.
   - 순서를 드래그로 다듬고, 아웃라인/원고(.md) 내보내기 또는 `🔮 융합 프롬프트`로 강의 초안 생성.
   - `💾 조립본으로 저장`: 만든 구성을 자산으로 보관하고 다시 불러올 수 있습니다.

## 데이터 · 이동 · 용량
- 모든 데이터는 이 브라우저의 **IndexedDB**에만 저장됩니다(서버 전송 없음).
- 폰↔노트북 이동은 **[데이터] 탭 → JSON 백업 내보내기/가져오기**로 합니다(가져오기는 병합).
- **오디오 자동 정리**: 원자화(분류·저장)가 끝나면 그 강의의 원본 오디오를 자동 삭제해 용량을 확보합니다
  (기본 켜짐, [데이터] 탭에서 끌 수 있음). 자막·아톰·설계·조립본은 유지됩니다.
  강의별 `🗑 오디오만 삭제`, 일괄 삭제도 지원합니다.

## 설치
- **데스크톱(크롬/엣지):** 주소창의 설치 아이콘 → "설치".
- **아이폰(사파리):** 공유 → "홈 화면에 추가".
- **안드로이드(크롬):** 메뉴 → "앱 설치".

## 선택 연동(모두 선택 사항, 키는 브라우저에만 저장)
- **Anthropic API** — 원자화·융합을 클로드에 직접 요청(`⚡ 자동`).
- **OpenAI 호환 Whisper 전사 API** — 실시간 자막이 안 되는 기기에서 녹음 파일을 자동 전사.

## 기술 메모
- 순수 정적: `index.html` + `app.js`(바닐라 JS, 단일 파일) + `studio.css`.
- PWA: `manifest.webmanifest` + `sw.js`(오프라인 셸 캐시). 아이콘은 루트 `/icons/` 공용.
- 녹음: `MediaRecorder`, 실시간 자막: `SpeechRecognition`(webkit), 저장: `IndexedDB`.
- 브라우저 지원: 녹음은 대부분 지원. 실시간 자막은 크롬/엣지/안드로이드 크롬. iOS Safari는 자막 미지원(녹음은 정상).
