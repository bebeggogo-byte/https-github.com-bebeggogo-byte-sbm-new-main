# 강의 스튜디오 (Lecture Studio)

강의를 **녹음 → 원자화 → 조립**하는 개인용 설치형 웹앱(PWA).
백엔드 없이 브라우저 안에서만 동작하며, 컴퓨터와 폰에 각각 설치해 오프라인으로 쓸 수 있습니다.

주소: `https://nedabah.org/studio/`

## 무엇을 하나
현장에서 무선마이크로 강의하는 소리를 노트북 마이크로 **녹음**하고, 지원 브라우저(크롬·엣지·안드로이드)에서는 **실시간 자막**을 함께 기록합니다.
그 원본을 **클로드로 원자화**해 "지식 아톰"(개념·정의·사례·예화·비유·통계·인용·질문·적용·실천·반론·전환)으로 쪼개 저장·분류하고,
나중에 원하는 주제의 새 강의로 **조립·조합·융합**합니다.

## 흐름
1. **녹음** — 제목·주제·태그·메모 입력 후 녹음. 실시간 자막이 쌓입니다.
2. **강의원본** — 저장된 녹음/자막을 확인·편집. 여기서 원자화합니다.
3. **원자화** — `① 프롬프트 복사` → 클로드에 붙여넣기 → 나온 JSON을 `② 붙여넣기` 하면 아톰이 자동 생성·분류됩니다.
   (설정에 Anthropic API 키를 넣으면 `⚡ 자동 원자화`도 가능)
4. **아톰** — 검색·유형·주제·태그로 분류/편집. 재사용할 아톰을 **조립대**에 담습니다.
5. **조립대** — 새 강의 주제를 정하고 담은 아톰의 순서를 바꿔 아웃라인/마크다운으로 내보내거나,
   `🔮 융합 프롬프트`로 클로드가 하나의 강의 초안으로 엮어 줍니다.

## 데이터 · 이동
- 모든 데이터는 이 브라우저의 **IndexedDB**에만 저장됩니다(서버 전송 없음).
- 폰↔노트북 이동은 **[데이터] 탭 → JSON 백업 내보내기/가져오기**로 합니다(가져오기는 병합).

## 설치
- **데스크톱(크롬/엣지):** 주소창의 설치 아이콘 → "설치".
- **아이폰(사파리):** 공유 → "홈 화면에 추가".
- **안드로이드(크롬):** 메뉴 → "앱 설치".

## 선택 연동(모두 선택 사항, 키는 브라우저에만 저장)
- **Anthropic API** — 원자화·융합을 클로드에 직접 요청(`⚡ 자동`).
- **OpenAI 호환 Whisper 전사 API** — 실시간 자막이 안 되는 기기에서 녹음 파일을 자동 전사.

## 기술 메모
- 순수 정적: `index.html` + `app.js`(바닐라 JS, 단일 파일) + `studio.css`.
- PWA: `manifest.webmanifest` + `sw.js`(오프라인 셸 캐시). 아이콘은 루트 `/icons/` 공용.
- 녹음: `MediaRecorder`, 실시간 자막: `SpeechRecognition`(webkit), 저장: `IndexedDB`.
- 브라우저 지원: 녹음은 대부분 지원. 실시간 자막은 크롬/엣지/안드로이드 크롬. iOS Safari는 자막 미지원(녹음은 정상).
