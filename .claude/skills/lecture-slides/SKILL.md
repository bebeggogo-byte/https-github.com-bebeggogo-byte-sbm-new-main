# 강의 슬라이드 자동 제작 (네다바웨이)

**먼저 `pptx` 스킬을 로드**해 pptxgenjs 함정·검증·렌더 QA 절차를 따른다.
이 스킬은 그 위에 네다바웨이 브랜드 토큰과 안티 AI-slop 레이아웃 시스템을 얹는다.

## 테마 라이브러리 — 주제에 맞게 선택 (품질 기준은 고정, 토큰만 교체)

사용자가 테마를 지정하지 않으면 **주제를 보고 추천 후 진행**한다. 애매하면 samsung.

| 테마 | 어울리는 주제 | 다크 배경 | 페이지/잉크 | 특징 |
|---|---|---|---|---|
| **samsung** (기본) | 밝고 친근한 신뢰감 | `1428A0` | 흰/`000000` | 삼성 블루 포인트(활동 라벨·통계 숫자), 라이트블루 틴트 `E4EAF9`, 카드 `F7F7F7` |
| **apple** | 무채색 절제, 내용만 남길 때 | `000000` | 흰/`1D1D1F` | 흑백+그레이, 무채색 |
| **serif** | 말씀 묵상·문학·역사 | `1F1A15` | 흰/`1F1A15` | 제목 Cambria 세리프, 골드 `D9B96A` 결단 |
| **nedabah** | 공동체 브랜드 행사·수료식 | `4E3117` | 흰/`2C2118` | 브라운·골드 `E3C77E` |
| **midnight** | 리더십·비전·전략 | `1E2761` | 흰/`1C2340` | 네이비+아이스블루 `CADCFC` |
| **forest** | 성장·회복·습관·자연 | `2C5F2D` | 흰/`1E3320` | 그린+모스 `97BC62` |
| **terracotta** | 공동체·환대·가족 | `8E3B31` | 흰/`3A2A26` | 따뜻한 테라코타·샌드 |
| **cherry** | 도전·결단·회개 | `990011` | 흰/`2B1518` | 강한 체리 레드 |

모든 테마 공통: 페이지는 흰 배경 + 잉크 텍스트, 다크 샌드위치(표지·질문·마무리)만 테마 다크색.
카드·거대 숫자 틴트는 각 테마의 연한 톤. 정확한 토큰은 `studio/app.js`의 `SLIDE_THEMES` 참조.

## 디자인 토큰 — 삼성 스타일 (기본)

- **흰 배경 + 검은 글씨가 기본.** 포인트 컬러는 삼성 블루 `1428A0` — 활동 라벨·통계 숫자 등 절제된 지점에만.
- 색: 본문 잉크 `000000` / 캡션·키커 `75777B` / 진한 서브 `4D5256` / 카드 `F7F7F7`(One UI 라운드) / 거대 숫자·글리프 틴트 `E4EAF9`(라이트블루) / 다크 배경 위 서브 `B7C4EE`
- **다크 샌드위치**: 표지·질문·마무리 = 삼성 딥블루 `1428A0` 수직 그라디언트(흰 글씨), 나머지 전부 흰색
- 밝고 친근하되 단정하게 — One UI의 라운드 카드 감성, 과한 장식 금지는 동일.
- 폰트: `Malgun Gothic`. 표지 제목 54-60pt(중앙), 섹션 거대숫자 300-340pt(틴트), 제목 30-40pt, 본문 14-20pt, 키커 14-15pt(자간 `charSpacing: 4`)
- 본문 리스트에 불릿 글리프(•)를 쓰지 않는다 — 행간·여백으로 구분 (애플은 불릿을 안 쓴다)
- 캔버스: `pres.layout = 'LAYOUT_WIDE'` (13.33×7.5in), 여백 최소 0.9in, 여백 40% 이상 유지

## 레이아웃 레퍼토리 — 같은 레이아웃 연속 금지

1. **표지**: 블랙 배경, 전부 중앙 — 그레이 키커(자간) + 60pt 흰 대제목 + 그레이 부제
2. **선언**: 흰 배경 중앙에 큰 검정 문장 하나(40-44pt) — 애플 히어로 카피
3. **섹션**: 거대한 라이트그레이 숫자(340pt, 우측)가 그래픽, 검정 제목 좌하단
4. **번호 서클 행**: 검정 원(0.85in) + 굵은 검정 헤더 + 그레이 서브, 3행
5. **질문 전용**: 블랙, 흰 질문 하나 중앙(40pt) + 그레이 보조행
6. **인용**: 거대한 " 글리프(220pt Cambria, 라이트그레이) + 검정 인용 + 그레이 출처
7. **활동**: 그레이 자간 라벨 "활동" + 큰 라이트그레이 숫자 단계(54pt) + 검정 단계 텍스트
8. **두 칼럼 대비**: `F5F5F7` roundRect 카드 2장(중립), 검정 헤드 + 그레이 항목
9. **통계**: 거대 검정 숫자(96-120pt) 중앙 + 그레이 라벨
10. **마무리**: 블랙, 그레이 얻음 + 흰색 굵은 결단(40pt)

## 잡스 원칙 (실제 애플 키노트 분석 기반)

- **빌보드 테스트**: 슬라이드는 3초 안에 읽혀야 한다. 잡스는 12장에 단어 19개.
  한 단어·한 숫자·한 문장 슬라이드가 덱의 절반 이상, content(불릿) 슬라이드는 1/3 이하.
- **다크 그라디언트**: 다크 슬라이드는 순색이 아니라 미묘한 수직 그라디언트(위 +10% 밝게) — 잡스 키노트 시그니처.
  pptxgenjs는 gradFill 미지원 → 그라디언트 배경 이미지를 만들어 깔거나, `studio/app.js`의 dzSlide gradFill XML 참조.
- **네거티브 트래킹**: 40pt+ 대형 타이포는 자간을 살짝 좁혀라(-0.5~-1.5%) — 애플 대형 타이포의 비밀. pptxgenjs `charSpacing: -1`.
- **이미지는 한 장, 크게**: 이미지를 쓸 때는 슬라이드당 1장, 풀블리드로. 자잘한 장식 이미지 금지.

## 배경 사진

- 사진이 힘을 실어줄 슬라이드(표지·구간·질문·인용·마무리)에만, **덱당 2~4장**.
- 처리 공식: **풀블리드(1920×1080 center-crop) + 검정 오버레이 42~55% + 흰 글씨**. 텍스트 대비가 최우선.
- 소싱: 사용자가 준 사진 > Pexels/Unsplash API(무료, 상업적 사용 가능; 검색어는 영어 구체 명사구 예: "open wooden door light") > 사진 생략(다크 그라디언트 폴백).
- pptxgenjs: `slide.addImage({path, x:0, y:0, w:'100%', h:'100%'})` 후 검정 사각형 `transparency: 50` 오버레이, 텍스트는 그 위에.
- 앱 렌더러(`studio/app.js`)는 동일 공식 내장: 클로드가 JSON에 `imageQuery`를 넣으면 Pexels 키로 자동 소싱하거나 사용자 사진 선택 모달을 띄운다.

## 금지 — AI 생성 티가 나는 것들

- 제목 밑 라인 / 색 바·스트라이프(가로·세로·카드 모서리 전부) ← 최다 위반
- 크림/베이지 기본 배경 (흰색 또는 순수 블랙만)
- 여러 색 사용 — 흑백+그레이가 기본, 색은 사용자가 요청할 때만
- 불릿 벽 (5개 초과, 서브 설명 없는 나열)
- 본문 가운데 정렬 (디스플레이 슬라이드 제외)
- 클리셰 문구: "~의 여정", "함께 알아보겠습니다", "다양한", "효과적인"
- 전 슬라이드 동일 레이아웃

## 절차

1. 소스(설계.md / 아톰 / 주제) 읽고 **내러티브 아웃라인** 먼저: 8~16장, 한 장 한 메시지, 도입→전개→활동→결단
2. pptxgenjs 스크립트 작성 (색상 `#` 금지, `margin: 0`, 노트는 `addNotes`)
3. `validate.py` → LibreOffice 렌더 → **시각 QA**(오버플로·정렬·간격) → 수정 반복
4. 완성 .pptx와 함께 슬라이드 이미지 미리보기 제공
