# 강의 슬라이드 자동 제작 (네다바웨이)

**먼저 `pptx` 스킬을 로드**해 pptxgenjs 함정·검증·렌더 QA 절차를 따른다.
이 스킬은 그 위에 네다바웨이 브랜드 토큰과 안티 AI-slop 레이아웃 시스템을 얹는다.

## 디자인 토큰 — 애플 스타일 (기본)

- **흰 배경 + 검은 글씨가 기본.** 색으로 꾸미지 않고 크기·굵기·그레이 단계로 위계를 만든다.
- 색: 본문 잉크 `1D1D1F` / 캡션·키커 `86868B` / 진한 서브 `6E6E73` / 카드 `F5F5F7` / 거대 숫자·글리프 틴트 `E8E8ED` / 다크 배경 위 서브 `A1A1A6`
- **다크 샌드위치**: 표지·질문·마무리 = 순수 블랙 `000000`(흰 글씨), 나머지 전부 흰색
- 악센트 컬러 없음이 기본. 사용자가 브랜드 색(네다바웨이 브라운 `6B4423`)을 요청할 때만 최소로.
- 폰트: `Malgun Gothic`. 표지 제목 54-60pt(중앙), 섹션 거대숫자 300-340pt(틴트), 제목 30-40pt, 본문 14-20pt, 키커 14-15pt(자간 `charSpacing: 4`)
- 본문 리스트에 불릿 글리프(•)를 쓰지 않는다 — 행간·여백으로 구분 (애플은 불릿을 안 쓴다)
- 캔버스: `pres.layout = 'LAYOUT_WIDE'` (13.33×7.5in), 여백 최소 0.9in, 여백 40% 이상 유지

## 레이아웃 레퍼토리 — 같은 레이아웃 연속 금지

1. **표지**: 블랙 배경, 전부 중앙 — 그레이 키커(자간) + 60pt 흰 대제목 + 그레이 부제
2. **선언**: 흰 배경 중앙에 큰 검정 문장 하나(40-44pt) — 애플 히어로 카피
3. **섹션**: 거대한 라이트그레이 숫자(340pt, 우측)가 그래픽, 검정 제목 좌하단
4. **번호 서클 행**: 검정 원(0.85in) + 굵은 검정 헤더 + 그레이 서브, 3행
5. **질문 전용**: 블랙, 흰 질문 하나 중앙(40pt) + 그레이 보조행
6. **인용**: 거대한 " 글리프(220pt Cambria, 라이트그레이) + 검정 인용 + 그레이 출처
7. **활동**: 그레이 자간 라벨 "활동" + 큰 라이트그레이 숫자 단계(54pt) + 검정 단계 텍스트
8. **두 칼럼 대비**: `F5F5F7` roundRect 카드 2장(중립), 검정 헤드 + 그레이 항목
9. **통계**: 거대 검정 숫자(96-120pt) 중앙 + 그레이 라벨
10. **마무리**: 블랙, 그레이 얻음 + 흰색 굵은 결단(40pt)

## 금지 — AI 생성 티가 나는 것들

- 제목 밑 라인 / 색 바·스트라이프(가로·세로·카드 모서리 전부) ← 최다 위반
- 크림/베이지 기본 배경 (흰색 또는 순수 블랙만)
- 여러 색 사용 — 흑백+그레이가 기본, 색은 사용자가 요청할 때만
- 불릿 벽 (5개 초과, 서브 설명 없는 나열)
- 본문 가운데 정렬 (디스플레이 슬라이드 제외)
- 클리셰 문구: "~의 여정", "함께 알아보겠습니다", "다양한", "효과적인"
- 전 슬라이드 동일 레이아웃

## 절차

1. 소스(설계.md / 아톰 / 주제) 읽고 **내러티브 아웃라인** 먼저: 8~16장, 한 장 한 메시지, 도입→전개→활동→결단
2. pptxgenjs 스크립트 작성 (색상 `#` 금지, `margin: 0`, 노트는 `addNotes`)
3. `validate.py` → LibreOffice 렌더 → **시각 QA**(오버플로·정렬·간격) → 수정 반복
4. 완성 .pptx와 함께 슬라이드 이미지 미리보기 제공
