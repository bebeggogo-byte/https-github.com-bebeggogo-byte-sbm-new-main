# 강의 슬라이드 자동 제작 (네다바웨이)

**먼저 `pptx` 스킬을 로드**해 pptxgenjs 함정·검증·렌더 QA 절차를 따른다.
이 스킬은 그 위에 네다바웨이 브랜드 토큰과 안티 AI-slop 레이아웃 시스템을 얹는다.

## 브랜드 토큰

- **색 (60-30-10)**: 지배 `FFFFFF` / 보조 brown `6B4423`·brownD `4E3117` / 악센트 gold `B08A2E`(밝은 배경 위)·goldL `E3C77E`(어두운 배경 위) — **슬라이드당 악센트 1개**
- 틴트: `EFE6D8`(글리프), `E9DCC8`(거대 숫자), `F4EEE4`(카드) / 잉크 `2C2118`, 서브 `6E5F4E`, 뮤트 `9A8B77` / 활동 라벨 green `3F7D5A`
- **다크 샌드위치**: 표지·질문·마무리 = `4E3117` 배경, 나머지 = 흰색
- 폰트: `Malgun Gothic`. 표지 제목 54-60pt, 섹션 거대숫자 300-340pt(틴트), 제목 30-40pt, 본문 14-20pt, 키커 14-15pt(자간 `charSpacing: 4`)
- 캔버스: `pres.layout = 'LAYOUT_WIDE'` (13.33×7.5in), 여백 최소 0.9in, 여백 40% 이상 유지

## 레이아웃 레퍼토리 — 같은 레이아웃 연속 금지

1. **표지**: 골드 키커(자간) + 60pt 대제목 + 부제. 장식 없음
2. **선언**: 흰 배경에 큰 문장 하나(44pt), 핵심 단어만 gold
3. **섹션**: 거대한 틴트 숫자(340pt, 우측)가 그래픽, 제목은 좌하단
4. **번호 서클 행**: 브라운 원(0.85in) + 굵은 헤더 + 서브 설명, 3행
5. **질문 전용**: 다크, 질문 하나 중앙(40pt) + 골드 보조행
6. **인용**: 거대한 " 글리프(220pt Cambria, 틴트) + 이탤릭 인용 + 출처
7. **활동**: green 자간 라벨 "활동"(텍스트만) + 큰 틴트 숫자 단계(54pt) + 단계별 서브 설명
8. **두 칼럼 대비**: roundRect 카드 틴트 vs 브라운, 대비 구조(전/후, A/B)
9. **통계**: 거대 숫자(96-120pt) + 라벨
10. **마무리**: 다크, 얻음(뮤트) + 결단(goldL 40pt)

## 금지 — AI 생성 티가 나는 것들

- 제목 밑 라인 / 색 바·스트라이프(가로·세로·카드 모서리 전부) ← 최다 위반
- 크림/베이지 기본 배경 (흰색 또는 brownD만)
- 불릿 벽 (5개 초과, 서브 설명 없는 나열)
- 본문 가운데 정렬 (디스플레이 슬라이드 제외)
- 클리셰 문구: "~의 여정", "함께 알아보겠습니다", "다양한", "효과적인"
- 전 슬라이드 동일 레이아웃

## 절차

1. 소스(설계.md / 아톰 / 주제) 읽고 **내러티브 아웃라인** 먼저: 8~16장, 한 장 한 메시지, 도입→전개→활동→결단
2. pptxgenjs 스크립트 작성 (색상 `#` 금지, `margin: 0`, 노트는 `addNotes`)
3. `validate.py` → LibreOffice 렌더 → **시각 QA**(오버플로·정렬·간격) → 수정 반복
4. 완성 .pptx와 함께 슬라이드 이미지 미리보기 제공
